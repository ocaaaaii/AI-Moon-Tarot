# Creative Brief — 首頁品牌化改版 v7.0

**Author**: CA · **Date**: 2026-09-16 · **Status**: Draft（待你確認素材後進入 Plan Mode）

---

## 1. 一句話

把 `/` 從「四張圖並排的功能入口頁」，重做成「讓人願意截圖分享、看起來像付費級產品的世界觀官網首頁」。

## 2. 為什麼是現在

- 產品本體（塔羅店鋪、神社、眾神之庭、天啟）已經有相當深度：7 位靈魂 × 雙身分、6 個 Sacred Realms 儀式、100 籤詩、星座神諭、故事 CG。
- 但首頁完全沒有傳達這些。現在的首頁把整個世界壓縮成四張縮圖 + 兩個按鈕，**資訊密度與情緒密度都遠低於產品實際的份量**。
- 下期要談付費方案 / 會員 / 曜刻儲值。沒有人會為一個「看起來像 side project」的入口付費，品牌力必須先於金流。

## 3. 現況 vs 目標

| | 現在 | 目標 |
|---|---|---|
| 版面 | 單屏、置中、四卡平鋪 | 長捲軸敘事頁，5 個區段 |
| 導航 | 無 | 固定頂列 + 錨點捲動（HOME / WORLD / TAROT / CHARACTERS / STORY / ENTER） |
| 主視覺 | 80px 旋轉 logo | 全幅 KV 大圖 + 疊字標語 + 主 CTA |
| 角色 | 完全沒露出 | CHARACTERS 七魂群像區 |
| 語氣 | 功能說明（「選一扇門」） | 世界觀敘事（英文大標 + 中文副標） |
| 情緒目標 | 「我要去哪個功能」 | 「這是一個世界，我想進去」 |

## 7. 明確不做（本期）

- 不建 WORLD / CHARACTERS / STORY 的獨立路由頁。
- 不動 `/tarot`、`/shrine`、`/garden`、`/stories` 任何一行。
- 不接金流、不做會員牆、不改 `ENFORCE_MEMBERSHIP`。
- 不做 3D 首頁（Three.js 留在卡牌互動，不上首屏）。
- GSAP **只用在首頁**，不回頭重構其他四個世界的動畫。

## 8. 風險（前三名）

1. **效能（風險最高）。** `images.unoptimized: true` 讓每張圖原檔直出。目前 `/public/assets` 有 20+ 張 2.7–3.5MB 的 PNG；首頁若照現況用 KV + 七張角色圖，傳輸量會超過 25MB。必須在放進 `/public` 前就壓好（見 PRD P0-7）。
2. **KV 構圖的先天限制。** 兩張圖都是滿版繪製、沒有預留大片暗部給文字，桌機只能把文案放在右上星空、手機只能放在漸層帶上。可行，但排版自由度受限；若日後重出 KV，請把「文字要疊在哪」當成構圖條件。
3. **雙動畫庫的衝突與洩漏。** GSAP 與 `motion/react` 若搶同一屬性會產生抖動與難以重現的 bug；ScrollTrigger 未清理會在路由切換時洩漏。靠 §6 決策 5 的分層規則與 `gsap.context()` cleanup 控制（見 PRD P1-7）。
4. **無法驗證成效。** 專案目前**零分析工具**，改版後沒有任何數據能證明「更能賣」。見 PRD §3 與 §7。
